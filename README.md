# RUNAK MUSIC
A responsive anime-inspired music player styled to match the supplied reference screenshot.

## Run
Open `index.html` in a modern browser. Click **Add music** or **Uploads** to select audio files from your device. The player supports local browser playback, seeking, volume, shuffle, repeat, previous and next.

## Deploy on Vercel
Upload this folder to a new Vercel project. It is a static site: no build command is required; `index.html` is the entry page.

## Note
The featured playlists are visual demo cards. The website plays audio files you select locally; it does not stream copyrighted songs from YouTube or include commercial tracks.
